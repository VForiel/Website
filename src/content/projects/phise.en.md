PHISE (**PH**otonic **I**nterferometric **S**imulation for **E**xoplanets) is a Python library developed as part of my PhD thesis. It enables end-to-end simulation of a photonic interferometric instrument, from the astrophysical scene to the detected signal.

## Features

- Modeling of photonic components (couplers, phase shifters, MMIs)
- Coherent propagation simulation through an interferometer
- Realistic signal generation including noise and instrumental effects
- Statistical analysis of detection performance
- Modular architecture for testing different instrumental configurations

## Technologies

Python, NumPy, SciPy, Numba, Matplotlib, Astropy

## Impact

Core tool of my PhD, used to design, optimize and validate interferometric architectures for direct exoplanet detection through kernel-nulling.
