Allay Core is the foundational architecture that powers the Discord bots in the Allay ecosystem. Written in Python (Discord.py), this modular, open-source project focuses on accessibility and feature customization for the Gunivers community.

It accelerates the development of other bots within the organization by providing a robust foundation, utility tools, and simplified community maintenance.
