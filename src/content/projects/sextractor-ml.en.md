Having an algorithm that allows detecting light sources in an image is obviously crucial in astronomy. But such algorithms are heavy to run and give a positive or negative result, no matter if it is in the gray zone. So, what if we use an object detection model to perform such tasks? It can probably run faster and give a kind of uncertainty on each detection.

The goal of this project was to try to make such an ML model. Unfortunately, due to the unknown number of outputs, designing such a model was much more complex than initially thought and it was not possible to create it in 20 hours (officially, but near 50 hours in practice) without a deep mastering of the ML world.
